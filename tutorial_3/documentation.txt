2.1. Why are the variables declared as private?
Variables are declared as private to implement encapsulation (data hiding). This protects sensitive student data from unauthorized or accidental direct access and modification from outside the Student class.

2.2. What happens if the variables are declared public?
If the variables are declared public, any external class can directly access and modify their values without restriction. This breaks data security and allows invalid data (such as a negative CGPA or an empty ID) to be assigned directly.

2.3. Why do we use getters and setters?
Getters and setters provide controlled access to private variables. Getters allow other classes to safely read the values, while setters allow updating the values safely (and let us add validation rules in the future before saving the data).
